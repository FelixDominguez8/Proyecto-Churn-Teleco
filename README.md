# Proyecto-Churn-Teleco

Para este proyecto se realizó un desarrollo de ciencia de datos sobre el dataset TelcoClientesFuga el cual se centraba sobre la fuga(churn) en ambos la aplicación de ciencia de datos sobre un notebook de Python para la limpieza, transformación, modelado y métricas como en la realización de un dashboard en PowerBI para la visualización de los datos

### Roles y Trabajo Colaborativo
- Felix Dominguez: Desarrollo del Notebook en la ingesta, preparación de datos, análisis exploratorio y modelado
- Hailton Amaya: Diseño e implementación del dashboard interactivo en PowerBI
- Ambos: Redacción del Informe
