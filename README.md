# Proyecto-Churn-Teleco

Para este proyecto se realizo un desarrollo de ciencia de datos sobre el dataset TelcoClientesFuga el cual se centraba sobre la fuga(churn) en ambos la aplicacion de ciencia de datos sobre un notebook de Python para la limpieza, transformacion, modelado y metricas como en la realizacion de un dashboard en PowerBI para la visualizacion de los datos
